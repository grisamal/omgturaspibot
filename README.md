## ⚡️ Зачем этот бот?

Официальный сайт расписания ОмГТУ на мобильных устройствах не всегда удобен: приходится вручную искать группу, вглядываться в списки и путаться в расписании двух подгрупп.

Этот бот решает эти проблемы:
- Расписание открывается в один клик прямо в мессенджере.
- Поддерживается абсолютно любая группа университета и колледжа ОмГТУ.
- Работает моментально благодаря локальному L1 RAM кэшированию и пулу постоянных сетевых соединений.

---

## 🚀 Основные возможности

- 👥 **Умная фильтрация по подгруппам:**
  - При выборе **1-й** или **2-й подгруппы** бот показывает только твои пары (общие лекции + свои практические и лабораторные).
  - Для старост есть режим **«вся группа»** — разделённые пары наглядно отмечены метками `[1 п/г]` и `[2 п/г]`, упорядочены хронологически.
- 🔔 **Автоматические уведомления об изменениях:**
  - Бот в фоновом режиме каждый час сверяет расписание с базой `rasp.omgtu.ru`.
  - Если пару перенесли, отменили или заменили аудиторию — бот пришлёт персональное оповещение с подробностями.
- 🔢 **Честная сетка звонков:**
  - Номера пар соответствуют официальному расписанию звонков университета.
- 📅 **Удобная навигация:**
  - Кнопки быстрого доступа: `Сегодня`, `Завтра`, `Неделя`.
  - Интерактивный календарь и стрелки для просмотра любого дня.
- 🔍 **Умный поиск группы:**
  - Автоматическое исправление случайной раскладки (например, `CBKo-261` $\rightarrow$ `СВКо-261`).

## 🛠 Стек технологий

- **Язык:** Python 3.11+
- **Фреймворк:** [Aiogram 3.x](https://docs.aiogram.dev/) (асинхронный Telegram Bot API)
- **База данных:** SQLite + [aiosqlite](https://github.com/omnilib/aiosqlite) (высокопроизводительный режим WAL, пулы и индексы)
- **Сетевой стек:** [aiohttp](https://docs.aiohttp.org/) (ClientSession с TCPConnector и keep-alive)
- **Кэширование:** двухслойный кэш (L1 RAM кэш с TTL 5 минут + L2 SQLite persistent cache)
- **API источника:** официальное расписание [rasp.omgtu.ru](https://rasp.omgtu.ru)

## 📦 Быстрый запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/grisamal/omgturaspibot.git
cd omgturaspibot
```

### 2. Установка зависимостей
```bash
python -m venv venv
# Linux / macOS
source venv/bin/activate
# Windows
.\venv\Scripts\activate

pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Скопируй `.env.example` в `.env`:
```bash
cp .env.example .env
```
Укажи токен бота в `.env`:
```env
BOT_TOKEN=твой_токен_от_BotFather
```

### 4. Запуск бота
```bash
python main.py
```
